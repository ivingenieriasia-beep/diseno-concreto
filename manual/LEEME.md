# Manual del equipo: Auxiliar IV con RAM Elements

- `Manual_RAM_Auxiliar_IV.pdf`: el manual para repartir.
- `manual.html`: el original. Las imágenes están en `img/` y las fuentes en `fuentes/`, así que funciona sin internet.

Para volver a sacar el PDF después de editar el HTML: ábrelo en Chrome o Edge → Imprimir → Guardar como PDF,
con márgenes «Predeterminados», «Gráficos de fondo» activado y «Encabezados y pies de página» desactivado
(el pie con el número de página lo pone la hoja de estilos).

Las capturas son de la app con el edificio de prueba (`scripts/ram/edificio_prueba.py`) y con un modelo real.
Cuando cambie la interfaz, conviene repetirlas.
